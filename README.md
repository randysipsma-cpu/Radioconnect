# RadioConnect

Een multi-station communicatieplatform voor internetradio.

## Ontwikkeling
- `main`: gereserveerd voor stabiele releases
- `develop`: ontwikkeling en testen

## Geplande onderdelen
- Gescheiden radiostations en rooms
- Realtime chat en privéberichten
- Beveiligde bestandsopslag
- Rollen en toegangscontrole
- Radioplayer en DJ-roosters
- Pushmeldingen en installeerbare PWA

## Beveiliging
Geen secrets in GitHub. Station- en roomrechten worden altijd op de server gecontroleerd. Geen productie-deployment zonder expliciete goedkeuring.
